Teach signs

Type the English word, then sign it into the camera each time you are asked. Lower your hands below the dashed line between repetitions. Five repetitions per sign works well.

    Recognise a recorded video

    Pick a video of someone signing. Each frame is processed on this device with the same pipeline as the live camera, then the signs you taught are matched.

      Device check

      Measures how fast this phone or computer runs each stage. The model speed test runs the 4.5M-parameter SignBridge network shape with random weights: it measures speed only and recognises nothing.

      Settings

      Hands above the dashed line count as signing. Lower it if signs are missed; raise it if resting hands trigger signs.
      Higher accepts signs that look less like the taught examples, such as a different signer. Unsure matches are shown as [word?].
